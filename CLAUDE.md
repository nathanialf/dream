# Notes for AI agents working in this repo

This is a **matching disassembly** of the *Dream: Land of Giants* prototype (codename Project Dream; SNES, Rare, c. 1995,
the build that became *Banjo-Kazooie*). Read `docs/LEGAL.md` first. The rule that
matters most: **no ROM, no extracted data, no build output, no literal byte runs in
committed sources, ever.** `tools/check_no_rom.sh` runs in the pre-commit hook as a
backstop.

Read `docs/NOTES.md` before doing anything substantive: it holds the memory map, the
program structure, the sound-driver protocol, the toolchain evidence, and the open items.

## Project state (verify before assuming)

- `make` extracts `baserom/DREAM.sfc` into `data/`, assembles `src/` with asar 1.91
  (`tools/bin/asar`, built locally), and checks the SHA-1. The round trip is byte-identical.
  `make spc` assembles the SPC700 driver disassembly and compares it to the ROM bytes.
- `src/` is **generated** by `tools/emit_asar.py` from the tracer `tools/trace65816.py`
  plus the curated label file `tools/names.txt`. Hand edits to `src/` are lost on
  `make regen`. Improve `names.txt` (or the tracer) instead, then `make regen && make`.
- `spc/driver.asm` is generated by `tools/trace_spc700.py` the same way.
- Labels adopted from the public DKC1/2/3 disassemblies are credited in
  `docs/dkc_crossref.md`; never paste code or comments from those projects.

## Conventions

- HiROM: file offset `f` is CPU address `$C0:0000 + f`; labels are `sub_C0XXXX` /
  `loc_C0XXXX` / `data_C0XXXX` until named. Mirror-bank references keep the ROM's bank
  byte via `$800000+(label&$FFFF)`.
- `names.txt` entries: `C0XXXX name [m0x0]` (code; the flag token forces tracing from
  an unreferenced entry), `data C0XXXX name`, `ram XXXX name`.
- Commit messages carry no AI attribution lines.
